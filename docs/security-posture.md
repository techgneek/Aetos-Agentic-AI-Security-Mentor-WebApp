# Security Posture

AetosAI Security Mentor is designed with a security-first mindset.

Return to the [Documentation Index](index.md).

The public documentation focuses on the defensive intent of the product rather than the private implementation.

## High-Level Themes

- secure AI mentoring
- controlled user interactions
- evidence-oriented review
- trust-boundary awareness
- operational monitoring and accountability

## Public Summary

The app is meant to help people think carefully about safe AI behavior, prompt handling, and agent usage.

That means the public story centers on what the app does and why it exists, not how the private code is built.

## Principles

- least privilege
- clear boundaries
- human review when needed
- traceable decisions
- practical evidence collection
