# Getting Started

This page explains the public user flow for AetosAI Security Mentor.

Return to the [Documentation Index](index.md).

## Basic Flow

1. Open [aetosai.io](https://aetosai.io).
2. Choose a question, topic, or scenario.
3. Continue in chat for a written exchange.
4. Use voice if you want hands-free interaction.
5. Review the guidance and follow the public walkthroughs.

## What To Expect

- A security-first mentoring experience
- Clear explanations for common AI safety concerns
- Guided paths that help you stay focused on the question you asked
- Public documentation that describes the app without exposing implementation details
