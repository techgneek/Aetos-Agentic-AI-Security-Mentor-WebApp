# Overview

AetosAI Security Mentor is a voice-enabled Agentic AI Security Mentor built to help people learn, test, and explain secure AI behavior.

Return to the [Documentation Index](index.md).

The public version of the project focuses on the product story:

- mentoring through chat and voice
- scenario-based learning
- reference-guided security explanations
- evidence-oriented review
- red-team style thinking for safer AI systems

## Why It Exists

The goal is to make secure AI behavior easier to understand and practice.

The app is meant to support teams that need a practical way to talk about prompt safety, agent boundaries, operational review, and defensive decision-making.
